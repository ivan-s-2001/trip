# trip ♥

Личный PWA-лендинг на 10–17 октября 2026: до поездки — «До грустного момента», во время командировки — обратный отсчёт до возвращения, ежедневные главы, письма, фотографии и случайные записки от мужа. После 17 октября сайт превращается в маленький архив поездки.

## Что уже есть

- динамический режим **до поездки / в поездке / день возвращения / после**;
- живой countdown и прогресс 10 → 17 октября;
- 60+ случайных записок без частых повторов;
- большая фотогалерея с 16 слотами и подписями;
- 8 ежедневных глав, которые открываются по датам;
- 8 писем «Открой, когда…»;
- «Банк объятий» с сохранением в localStorage;
- 12 причин «за что я тебя люблю»;
- случайные воспоминания;
- offline service worker;
- installable PWA;
- адаптивная mobile-first вёрстка;
- GitHub Pages workflow.

## Добавить ваши фотографии

Положить изображения в `assets/photos/`:

- `hero.jpg` — главная любимая фотография;
- `home.jpg` — фото для блока про возвращение домой;
- `01.jpg` … `16.jpg` — галерея.

Пока файлов нет, сайт показывает аккуратные художественные заглушки, поэтому страница не ломается.

## Сделать подписи по-настоящему вашими

В `app.js` находятся массивы:

- `NOTES` — случайные записки;
- `MEMORIES` — подписи к фото;
- `DAYS` — главы 10–17 октября;
- `LETTERS` — «Открой, когда…»;
- `REASONS` — причины;
- `RANDOM_MEMORIES` — случайные воспоминания.

Лучший следующий апгрейд — заменить шаблонные подписи реальными историями, именами, шутками и вашими фразами.

## Время вылета и возвращения

Сейчас переключение режимов происходит **в 00:00 локального времени устройства** 10 и 17 октября, потому что точное время рейсов пока не задано.

Когда оно будет известно, достаточно заменить `CONFIG.departure` и `CONFIG.returnDate` в начале `app.js`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует содержимое `main` через GitHub Actions.

Для нового репозитория GitHub может потребовать один раз выбрать **Settings → Pages → Source → GitHub Actions**. После этого каждый push в `main` будет обновлять сайт автоматически.
