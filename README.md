# trip — наше маленькое место

Одноэкранное приложение поездки Рыбинск → Шереметьево → Тюмень → Курган и обратно, 10–17 октября 2026.

## Версия 1.9.0

- Один экран, постоянная строка «Дома ждём — я и коты», прогресс поездки.
- 64 коротких готовых текста: это редактируемые черновики, а не реальные воспоминания.
- Объятия удержанием две секунды, переключение открытых записок, сохранение выбора на устройстве.
- Фото и голос необязательны: отсутствие файлов не ломает сцену.
- Локальные Bootstrap Icons, PWA-кэш и веб-ресурсы внутри Android APK.

## Уведомления

Android: выход из Рыбинска, прибытие в Шереметьево/Рощино/Курган, выход из Кургана и возвращение в Рыбинск — по геозонам. Каждая дорожная веха уведомляет один раз за этап поездки. Прибытие не объявляется по расписанию самолёта.

Записки 11–16 октября открываются по времени Екатеринбурга (UTC+5). При разрешённой фоновой геолокации их уведомления приходят только когда последняя геозона — Курган. Без разрешения GPS личные уведомления остаются по времени, дорожные геоуведомления недоступны. Требуются разрешения точной геолокации, доступа всегда и уведомлений; доставка зависит от Android и энергосбережения.

PWA определяет геозону при открытии. Фоновый GPS реализован в Android, веб-версия не обещает фоновые геоуведомления.

## Ваши материалы

В `content.js` можно менять тексты каждого момента. Фотографии кладите в `assets/photos/`, голосовые в `assets/audio/` по именам из `media`. Только собственные материалы: приложение не подставляет чужие фото и не создаёт голос мужа.

## Проверка

QA: добавьте `?qa=1` к адресу. Кнопка QA позволяет выбрать день, сцену, полёт и возврат домой. Отдельный APK QA устанавливается рядом с обычным.

GitHub Actions собирает Android и QA, GitHub Pages публикует веб-версию после изменения main. Логика времени, удержания и возвращения проверена локально; реальные geofence-переходы необходимо проверить на Android-устройстве.
