# Trip · интерфейс для двоих

Основа: тёплая бумага, тёмный текст, один винный акцент. Bootstrap Icons из локальных файлов. Системный шрифт для управления, книжный serif для писем. Внешние шрифты и библиотеки не требуются.

Редактор: главное действие — написать. Заготовки отдельно, вложения и интерактив раскрываются по необходимости. На широком экране ответы и подключение справа, на телефоне ниже формы. Предпросмотр ничего не отправляет. Черновик хранится локально, включая удаление вложений и редактирование запланированного сообщения.

Получатель: одна записка на экране, прокрутка длинного содержимого, кнопки перелистывания и список всех писем. Связь и работа без сети обозначены текстом. Открытые письма сохраняют состояние. Фото можно увеличить, неудачную загрузку повторить.

Размеры: управление не меньше 48 px, основной текст 16–17 px, подписи 12–14 px. Шаги отступов 4/8/16/24/32/48 px. Без градиентов на рабочих экранах. Видимый фокус, системные safe-area, reduced-motion. Тема пока светлая.

Проверка: ширина 375/768/1440 px, альбомная ориентация, увеличение текста; подключение владельца и получателя, черновик, предпросмотр, вложения, отправка, расписание, удержание, ответы и работа без сети.
